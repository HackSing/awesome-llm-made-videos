## 待核实线索

下面几条会影响署名或模型判断，需要看片或联系作者才能下结论：

1. **P(doom) 音乐 MV 的作者**：GitHub 上 [JohnHeibel/PDoomVideo](https://github.com/JohnHeibel/PDoomVideo) 公开了源码，并链接了 YouTube 原片；两条 B 站转载则把原作指向 X 账号 @other__reality 和 YouTube 频道 OtherReality。John Heibel 和 @other__reality 是否是同一人，目前还没核实。
2. **中秋拼贴动画**：@NFT_Chen 9/25 的帖子和 @ring_hyacinth 9/24 的帖子文案几乎逐字相同，@ring_hyacinth 第二天还说"昨天分享了拼贴画版本"。在对比两段视频之前，这条只标为疑似转载。
3. **@NFT_Chen 的"Claude 小人剪辑软件动画"**：播放量 42.5 万，是本章 X 上播放量最高的 Opus 作品之一。帖子用第三人称描述制作过程，疑似转载，原作者还没找到。
4. **@Delroy715 的"逼真 3D 水"**：帖子说代码已经开源，描述和 @Aurelien_Gz 的 [Clearwater](https://github.com/Aureliengmz/clearwater) 一致，但帖子本身没有写明来源。
5. **B 站"AE 像素级还原动态设计"**：作者称 GPT-6 操作 AE 还原了一位设计师的作品。模型做的是还原，创意和设计归原设计师。
6. **B 站 BV1buen64EPJ**：发布于 9/15，比 Opus 5.5 正式发布早一周，作者称是群友在灰度测试时跑的。模型身份无法核实。
7. **梗式标题**：一部分 B 站作品只有"震惊瘫坐""一句话生成"这类标题，没有简介。它们被标为"可能是作品"，证据等级 C 或 D，需要看片确认。
8. **B 站的 `copyright` 字段**：815 条里取值为 3 的有 528 条，为 1 的 252 条，为 2 的 34 条。3 的含义不明，没有用于判断是不是转载。

## 覆盖范围与局限

- **X**：以 [athemeroy/awesome-opus-5-5-videos](https://github.com/athemeroy/awesome-opus-5-5-videos) 截至 2026-09-25 15:21 UTC 的数据为起点，另加我们自己的 12 组 Top 搜索。GPT-6 相关内容只来自我们的搜索，覆盖明显少于 Opus 5.5。回执见 [`data/receipts/`](../data/receipts/)。
- **B 站**：16 组关键词，分别按发布时间和按播放量排序，都翻到结果尽头或页数上限为止。
- **自动筛选**：筛选只根据标题、简介和正文判断，没有看视频画面。所以"是不是模型做的""是不是转载"都只是初步结论，需要逐条人工复核后才能下定论。
- **没有覆盖**：YouTube 的系统采集（需要 API key），抖音、小红书、TikTok，以及 X 上的 Latest 时间线。
